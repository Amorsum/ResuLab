RESULAB / JOBS

把浏览器，连接到求职工作台。

这是个人预览版，BOSS 自动发送暂不可用。
当前可准备岗位、匹配经历、生成和下载专用简历。真实会话与附件发送仍待验证，按钮保持禁用，不会自动向招聘者发消息。

下载最新版扩展与完整安装说明 ↗

安装扩展

  1. 解压交付的 ResuLab-Jobs-Extension-0.1.2.zip。
  2. 在 Edge 地址栏输入 edge://extensions，或在 Chrome 输入 chrome://extensions。
  3. 开启“开发人员模式”，点击“加载解压缩的扩展”，选择包含 manifest.json 的文件夹。
  4. 启动本地 ResuLab 后，打开 求职工作台，点击“连接浏览器扩展”。请使用同一个浏览器登录 BOSS。

准备第一批岗位

  1. 填写岗位关键词和偏好，尝试搜索与收集；页面不支持时直接粘贴真实 JD。
  2. 到经历工作台确认材料，再运行智能匹配。缺少信息的条件保留“待确认”。
  3. 勾选岗位并生成简历。每个岗位有独立 PDF，原始经历不变。
  4. 展开岗位，核对改写来源、完整 PDF 和沟通文案。当前可下载文件，再到 BOSS 手动投递。

你需要知道

搜索目前尝试在 BOSS 设置关键词，其余条件在工作台本地筛选。BOSS 现有筛选可能限制采集范围；当前搜索适配也尚待实站验收。生成需要登录 ResuLab，使用已有 AI 服务。

记录只保存在当前浏览器。导出 JSON 保留岗位、简历内容与状态，PDF 需要单独下载。清理本地数据会丢失防重复记录，但不会删除 BOSS 上的消息。

扩展更新后请重新加载扩展并刷新工作台。中断后须重新连接、核验并主动继续；结果不明的操作不会自动重发。
