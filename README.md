# ResuLab — 简历与求职工作台

在线入口：[resulab.amorsum.top](https://resulab.amorsum.top) · [浏览器扩展下载与安装](https://resulab.amorsum.top/extension)

从真实经历出发，整理教育、项目和工作经历，制作简历，按目标岗位优化表达，并导出 PDF 或 Word。

## 可以做什么

| 功能 | 用法与条件 |
| --- | --- |
| 简历编辑、实时预览 | 手动填写简历，选择四种模板，调整字体、主题色、字号、行距和页边距 |
| 导入、PDF / Word 导出 | PDF / DOCX / 文本在本地读取，AI 提取需登录并确认；导出支持中文多页 |
| 项目经历库 | 上传项目介绍、读取源码或手动填写，整理个人和实习项目；选择项目用于岗位简历 |
| 定向写作 | 手动选材可直接填入简历；Agent 按岗位名称或 JD 推荐，确认选材后写作，核对后填入当前简历或创建岗位版本 |
| 针对岗位优化 | 分析当前简历与岗位的匹配情况，回答追问，对照原文选择应用建议，支持整批撤销；需登录 |
| 求职工作台 | 手动导入 JD、匹配证据、逐岗生成 PDF、审核和记录；AI 操作需登录 |
| 云端简历、账号 | 邮箱注册与登录，保存和打开云端简历，管理或注销本人账号 |
| BOSS 浏览器扩展 | 支持 Windows Edge / Chrome 安装；搜索与岗位读取仍待验证，自动沟通及附件发送暂不可用 |

## 开始使用

本地新版支持在经历库或编辑器点击“从项目生成经历”：读取公开仓库链接或 ZIP，选择文件，核对项目理解并补充个人贡献，生成后可直接编辑、局部重写，再确认存入经历库及填入简历。项目分析需要本地后端和模型服务；链接读取受平台可用性限制，可改传 ZIP。当前尚未发布到线上。

1. 打开 [ResuLab](https://resulab.amorsum.top)，点击“开始整理简历”。已有内容时可选择“继续编辑简历”。
2. 填写基本信息、教育、项目和工作经历，也可以导入 PDF、Word 或文本后，用 AI 提取并核对内容。
3. 选择经典、现代、极简或专业模板，调整排版，查看实时预览。长标题、邮箱和链接支持自动换行，长内容自动续页，PDF 按预览分页导出；手机端点击“预览简历”切换视图。
4. 如需针对岗位准备简历，在“经历库与定向写作”中整理素材，或使用“针对岗位优化”核对和应用改写建议。
5. 导出 PDF 或 Word；登录后也可以在编辑器中手动保存到云端，之后从“云端简历管理”打开。

手动编辑和导出无需登录，AI 功能和云端简历需要登录。所有主页面均可通过顶部“首页 · 全部功能”返回功能入口。

## 项目经历与岗位简历

在项目经历库选择“添加项目经历”，上传 PDF、Word、TXT 或 Markdown 项目介绍，也可直接填写；有源码时可以上传 ZIP 或读取公开仓库。实习项目可填写公司和个人角色。项目需核对确认后才参与选材；编辑已有项目时可直接修改用于简历的内容，也可以对照原始记录后更新项目描述。旧的非项目经历仍保留在原有数据和简历中。

进入“选择岗位与项目”，填写岗位名称或 JD，手动勾选项目，或让 Agent 根据岗位推荐并核对结果。可以预览后填入当前简历，也可以创建独立岗位副本；副本保留基础简历的教育、工作和技能等信息，并使用本次选择的项目。

本地体验以页面显示的存储状态为准：本地后端的数据仅保存在当前电脑，待上传内容尚未同步；Agent 需要登录和模型服务。支持导出备份及预览旧数据迁移，原始数据不会因切换项目界面而删除。

## 浏览器扩展安装

1. 前往 [扩展下载与安装页面](https://resulab.amorsum.top/extension)，下载 ZIP 并解压到固定文件夹。
2. 在 Edge 地址栏输入 `edge://extensions`，或在 Chrome 输入 `chrome://extensions`，开启“开发人员模式”。
3. 点击“加载解压缩的扩展”，选择包含 `manifest.json` 的文件夹。
4. 在同一浏览器打开 [求职工作台](https://resulab.amorsum.top/jobs)，点击“连接浏览器扩展”。

扩展目前通过 ZIP 安装，暂未上架扩展商店。更新时下载新版并覆盖原文件夹，在扩展管理页点击“重新加载”，再刷新工作台并重新连接。

## 保存与备份

本地新版的“我的简历”统一展示基础简历、岗位副本和历史记录。可以重命名、归组、复制、归档和恢复；切换前先保存当前稿，普通保存不反复生成备份。云端仍需手动同步，遇到版本冲突可对照云端或另存本机副本。

- 当前简历会自动保存在本机浏览器中；云端保存需要登录后手动操作。本机保存失败时可重试或直接导出当前简历备份；版本冲突时先备份或另存副本，再核对其他页面的内容。
- 经历库中“已保存到云端”的条目可跨设备读取；访客经历、待上传内容、岗位记录及本地备份仍在当前浏览器。清理数据前，请导出经历库 JSON 并下载需要的文件。部署尚未升级云端接口时，请继续保留本机备份。
- 使用 AI 提取、匹配或改写前，请核对提交的材料；生成后逐条检查事实和表达，再确认应用。

项目添加统一提供手动填写、上传文件和仓库链接入口。手动填写项目名称、描述、角色与时间即可确认保存，AI 整理为可选操作；ZIP 与仓库复用项目材料工作区。已有项目的原始材料仅供参考，避免重复编辑同一字段。
