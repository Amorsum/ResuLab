# ResuLab — 智能简历制作平台

在线简历制作工具，支持实时预览、多套模板、一键导出 PDF。

## 功能

- 📝 **表单录入** — 完整的中文简历信息采集（基本信息、教育、工作经历、技能等 10 个模块）
- 👁️ **实时预览** — 左侧填写，右侧即时渲染，所见即所得
- 🎨 **多套模板** — 经典 / 现代 / 极简三种风格，一键切换
- 🎛️ **排版自定义** — 字体（默认/宋体/等宽）、字号（12-18px）、行距（1.4-2.0x）、页边距（紧凑/标准/宽松）
- 🌈 **主题色** — 9 种预设主题色，实时生效
- 📄 **PDF 导出** — 一键导出高清 PDF，支持多页
- 🪄 **智能一页** — 自动调整字号和页边距，将内容压缩至一页
- 🔄 **智能排序** — 教育/工作/项目经历按时间自动排序
- 💾 **本地保存** — 数据自动存入浏览器，刷新不丢失

## 技术栈

| 层面 | 技术 |
|------|------|
| 框架 | React 18 + TypeScript |
| 构建 | Vite 6 |
| 样式 | Tailwind CSS 3 |
| 路由 | React Router v6 |
| 状态管理 | Context + useReducer |
| PDF 导出 | html2canvas + jsPDF |
| 持久化 | localStorage |

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器（默认 http://localhost:3000）
npm run dev

# 构建生产版本
npm run build
```
