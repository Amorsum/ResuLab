# ResuLab 求职助手 0.1.2（个人预览版）

此版本提供岗位工作台、Manifest V3 扩展、岗位匹配、定制 PDF、审核批次、附件传输与可恢复执行引擎。

**BOSS 自动发送尚不可用。** 登录后会话导航、稳定身份识别、专用附件选择和真实发送回执未完成实站验收，发行包的 `communicate`、`attach` 能力固定为关闭。搜索和读取使用候选 DOM 适配，可能因页面变化而停止；失败时可以手动导入 JD。模拟页面测试不代表 BOSS 已接入成功。

## 安装和启动

1. 打开 https://resulab.amorsum.top/extension 下载当前 ZIP；开发者也可在仓库根目录运行 `npm ci` 和 `npm run package:extension`。
2. 解压 `ResuLab-Jobs-Extension-0.1.2.zip`，或直接使用构建出的 `release-artifacts/jobs-extension` 目录。
3. 在 Edge 打开 `edge://extensions`（Chrome 为 `chrome://extensions`），开启开发人员模式，选择“加载解压缩的扩展”，选择包含 `manifest.json` 的目录。安装操作由用户完成。
4. 在同一个浏览器打开 `https://resulab.amorsum.top/jobs`，点击“连接浏览器扩展”。BOSS 登录也应在这个浏览器中完成。
5. 搜索、匹配、勾选岗位并生成简历；展开岗位审核查看事实来源、完整 PDF 和文案。当前可以下载专用 PDF，回到 BOSS 手动处理发送。

本地地址必须是 `127.0.0.1:3000`，不是 `localhost` 或其他端口。修改扩展代码后先构建，再在扩展管理页重新加载，最后刷新工作台并重新配对。扩展弹窗默认打开在线工作台，同时保留本地开发入口。

### 从 0.1.0 更新

如果之前加载的是解压后的目录，请把 0.1.2 ZIP 的文件解压覆盖到那个目录，然后在扩展管理页点击本扩展的“重新加载”，确认版本为 0.1.2；如果加载的是项目的 `release-artifacts/jobs-extension`，该目录已由构建更新，直接重新加载即可。最后刷新工作台，重新连接并发起一次上限为 1 的搜索。仅刷新工作台不会更新扩展脚本。

0.1.2 修复搜索控件异步加载、填值后页面状态尚未刷新便点击、页面顶部同名搜索按钮干扰的问题，并使用标签页就绪事件启动首次搜索，减少工作台切到后台后的计时器延迟影响。搜索等待有上限，登录/验证码和含糊控件仍会暂停。工作台显示具体停在哪个阶段。

已通过独立浏览器合成页面回归（延迟搜索框、占位提示识别、异步搜索值更新、同名按钮、关键词回读及完整 JD）。真实 BOSS 页面仍需用户验收，这些测试不代表实站已通过。

## 使用边界

- 当前搜索适配尝试设置并回读关键词，再读取分页列表及详情。城市、月薪范围、经验、学历、类型和排除公司在工作台本地过滤；BOSS 页面原有筛选会限制被采集的岗位范围。未知字段不被自动推断为满足条件。
- 默认读取 20 个，最多 50 个；上限包含读取失败的详情。列表重复、无法定位下一页、登录或验证提示会停止，不无限翻页。
- AI 使用现有已确认经历和既有模型服务。模型不能操作扩展。联系方式和排版不进入匹配输入，PDF 内的个人资料只在准备审核批次后传入扩展本机存储。
- 每批最多 20 个岗位，一次执行一个动作。提交、上传或点击按钮不等于发送成功。身份、会话、文件或回执无法核验时停止。
- 模拟执行中，需对方同意或不能新增专用附件时保留附件待办；不替换或删除 BOSS 已有附件。结果不明不自动重发。
- 浏览器、工作台或扩展后台重启后，任务暂停，需主动继续。暂停仅阻止后续动作，已经开始的动作无法撤回。
- 本机记录按 ResuLab 身份隔离，BOSS 防重复记录另外绑定稳定平台账号。换电脑、浏览器配置或清理浏览器数据前请导出记录并下载 PDF。JSON 导出不包含 PDF 二进制，也不是可直接导入并恢复执行的备份。
- 扩展仅申请 BOSS、指定 ResuLab 页面和闹钟权限，不读取 Cookie，不索取密码，不申请调试器或全站访问权限。

## 构建与测试

```text
npm run build:extension
npm run test:jobs
npx playwright install chromium
npm run test:jobs:browser
npm run package:extension
npm run test:extension:browser
npm run test:jobs:search
```

浏览器测试在独立无头 Chromium 中使用本机合成招聘页面、合成用户和模型响应，阻断外部网络访问，不读取日常浏览器的登录状态，不联系真实招聘者。验证报告位于项目的 `docs/competition/results/jobs/`。

## 真实接入待验收

2026-10-24 用户已登录 Edge。首次在应用内打开 BOSS 超时；随后 Windows Computer Use 返回：

> Computer Use has been stopped for this turn because it could not determine the current browser URL on Windows with enough confidence to enforce policy.

本轮因此停止浏览器操作，没有读取登录后的 DOM，也没有上传或发送真实简历。

后续实站接入必须先替换并验证候选选择器，完成“岗位详情 → 正确会话”的导航、稳定账号和招聘者标识、平台初次沟通是否自动发送默认文案、会话专用附件新增/选择、成功及失败回执识别。当前后台 `deliveryTab` 尚无经过实站验证的建立流程，不能仅改能力布尔值就宣称自动发送可用。只针对用户在审核页明确确认的真实岗位进行发送验收；记录通过的页面版本后再启用对应能力。
