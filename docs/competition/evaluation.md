## 2026-10-24：撤销与格式整理的区分

- 用户反馈“应用 → 预览并导出 → 撤销 → 再导出”外观相同，随后提供的三条建议主要整理空白和句末句号。经典模板项目描述采用普通段落，会折叠换行及连续空格，不能单凭 PDF 外观相近认定撤销失败。
- 在独立端口 3003、开发合成模式下按同一顺序复现：应用后预览和首份 PDF 包含合成句末句号，撤销后两个预览节点均恢复无句号原文，第二次 PDF 成功下载。未调用模型，未修改真实账号任务；该结果不等于已核实用户两份 PDF 的实际内容。
- 另行复现并修复：重复设置当前模板原先仍生成历史项；若在 Agent 应用后重复选择当前模板，一次撤销会停留在应用后内容。`SET_TEMPLATE` 对同值返回原 state；新增三项真实 reducer/撤销 hook 测试，修复前两项失败，修复后通过，覆盖不消耗重做记录及真实模板修改仍独立撤销。
- 建议区标注空白/句末句号整理，使用字面比较，不能作为岗位相关性、事实正确性或实质优化效果的评分。模型对真实 JD 的内容优化效果仍需 B 继续评测。
- 同一会话的选中字段全部回到 before 时显示“本批建议已恢复原文”，不再一直显示“本批建议已应用”；以当前字段逐字比较，不根据点击次数宣称恢复。22 项前端测试及生产构建通过。
- 浏览器额外验证：应用合成建议后重复点击当前模板，撤销一次即可恢复原文；重新导出的 PDF 渲染像素与应用后不同。应用状态随真实字段恢复变为“本批建议已恢复原文”。
