# 已有简历导入

入口：编辑器 → AI 智能填写 → 导入已有简历。

支持文字型 PDF、Word `.docx`、TXT 和 Markdown。文件先在浏览器本地读取，用户可修改提取的文本，再点击「提取并预览」调用原有模型。当前输入非空时，提供追加、替换、保留三个选项。预览确认前不修改简历；确认追加后可用 Ctrl+Z 整批撤销，继续沿用本机保存、云端保存和导出。

已有简历使用 `resume-import` 提取模式，只调用一次模型，不额外生成自我评价。未提供的学历、技能或语言水平留空；自我评价必须能在原文找到。提取仍需人工核对，尤其是多栏 PDF 的顺序、复杂表格和 Word 文本框。

文件限制为 10 MB、PDF 20 页、文本 60000 字，读取有停止入口及 60 秒超时。Word 在解析前检查 ZIP 目录的条目数及解压大小。扫描型 / 图片型 PDF 不含可提取文字时给出明确提示，目前不提供 OCR；旧 `.doc` 需先另存为 `.docx`。文件解析器按需加载，PDF 字符映射与字体资源随应用构建，不依赖外部 CDN。没有增加 AI 额度或更改线上模型配置。
