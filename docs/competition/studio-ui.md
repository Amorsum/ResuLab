# ResuLab Studio 视觉改版

2026-10-24。本次保留自用工作台定位，以暖白、石墨色与少量鸢尾紫建立统一视觉。没有引入额度、订阅或生产配置变更。

首页围绕当前简历组织信息，内容概览来自真实编辑器数据，三个入口分别用于整理经历、岗位优化、打开云端版本。统一品牌标识用于首页、编辑器、经历库及账号页面。编辑器减少彩色按钮堆叠，将主题色收进排版面板，预览默认适配容器宽度，保留手动缩放与原始导出尺寸。经历库、结果核对和 Agent 共用新的颜色、边框与间距。手机输入字号至少 16px，保留焦点轮廓和减少动态效果的偏好。
